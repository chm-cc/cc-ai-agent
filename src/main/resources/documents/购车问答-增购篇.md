# 增购常见问题与回答

#### 1. 家里已有一辆燃油车，第二辆选纯电还是插混？
如果已有油车能覆盖长途场景，第二辆强烈建议选纯电——日常通勤成本极低，油车+电车的组合是现阶段最灵活的家用车配置。只需确保有充电条件即可。

📚 推荐课程：[油车+电车：最优家庭组合方案](https://www.baidu.com/)

#### 2. 增购的小车是选微型电动车还是紧凑型轿车？
取决于补位角色：如果只是市内单人通勤、买菜接娃，微型电动车足够且停车方便、使用成本极低；如果需要偶尔带家人出行或跑城际，紧凑型轿车更实用。别为了偶尔的需求牺牲日常的便利性。

📚 推荐课程：[家庭第二辆车选购智慧](https://www.baidu.com/)

#### 3. 增购的车上谁的名？家庭多车牌照怎么规划？
如实回答：谁主开就上谁的名，保险理赔无纠纷。限牌城市需提前了解家庭第二块牌照的政策；不限牌城市则不用顾虑。注意夫妻间车牌过户规则各地不同。

📚 推荐课程：[家庭多车牌照与保险规划](https://www.baidu.com/)

#### 4. 已有轿车，增购 SUV 还是 MPV？
看增购目的：如果是为周末出游、走烂路、想要更大后备箱，选 SUV；如果是为了父母同住、多孩出行、需要真第三排，选 MPV。轿车 + SUV 是多数家庭的最优组合，轿车负责日常，SUV 负责多功能。

📚 推荐课程：[轿车 + SUV vs 轿车 + MPV 对比分析](https://www.baidu.com/)

#### 5. 增购预算有限，是买便宜新车还是精品二手车？
如果对二手车有一定判断力且不介意车龄 3-5 年，精品二手车性价比极高，尤其适合增购这种非刚需场景；如果图省心、在意质保和新车体验，买便宜新车更稳妥。建议两条路都看看再做决定。

📚 推荐课程：[增购：新车 vs 二手车决策树](https://www.baidu.com/)

#### 6. 两辆车每年的额外开销大概多少？值不值得？
增购的固定成本包括保险（第二辆无折扣约 3000-6000 元/年）、保养（500-2000 元/年）、停车费（视城市而定）和折旧。如果是纯电车，电费几乎可忽略。算好这笔账，再结合它带来的出行自由度和便利性，答案会很清晰。

📚 推荐课程：[家庭养车成本精算课](https://www.baidu.com/)
